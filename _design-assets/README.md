# Hyper Inkers design assets

This folder contains local assets used by the internal design-system board.

- `hi-logo.webp`: local copy of the current Hyper Inkers wordmark.
- `icons/README.md`: functional icon usage contract.

Existing website background assets remain in `/_hero-assets/` and are not duplicated:

- `color-blur.webp`: ambient color field used behind CTAs/hero content.
- `cta-splatter-orange.png`: orange splatter signature asset.
- Grain/noise: code-native SVG data image defined in the current foundation/page CSS.

Do not add a new background family without brand approval. Use the design-system Backgrounds section for approved positioning and opacity examples.
