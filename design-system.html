05 / Foundation

Shape & Motion

Hard-edged, restrained geometry keeps the brand industrial. Motion confirms interaction; it does not decorate idle screens.

13 / Quality

Accessibility Baseline

Accessibility is part of the component contract, not a final polish pass.

  • Keyboard firstEvery action is reachable and has a visible focus indicator.
  • Accessible namesIcon-only buttons use aria-label; decorative SVGs are hidden.
  • Readable contrastBody copy uses approved white/muted pairs; orange text is restricted.
  • 44px targetsTouch controls remain usable even when the visible icon is 16–24px.
  • Reduced motionNon-essential animations stop when the user requests less motion.
  • Meaning beyond colorError and success states include icons or text, not color alone.

14 / Developer handoff

Use the System

Start from the shared foundation files. Page CSS may compose components but must not redefine brand tokens.

01

Load foundations

Fonts, base tokens, icon contract, components, page CSS, then `hi-ds.css` last where existing pages require its overrides.

02

Compose by role

Choose color and component variants from intent: conversion, navigation, content or state.

03

Verify all widths

Check 1440, 430 and 360px, keyboard focus, assets, console errors and horizontal overflow.
